# botbirthday

Telegram-бот для напоминаний о днях рождения сотрудников: за 3 дня и в сам день.

## Возможности

- Хранение ФИО и даты рождения (год опционален) для каждого чата отдельно.
- Ежедневная проверка в заданное время: напоминание за 3 дня и в день рождения.
- Команды для управления списком прямо в Telegram.

## Установка

```bash
npm install
cp .env.example .env
```

В `.env` укажите:
- `BOT_TOKEN` — токен, полученный у [@BotFather](https://t.me/BotFather)
- `TZ` — часовой пояс (по умолчанию `Europe/Moscow`)
- `REMINDER_TIME` — время ежедневной проверки в формате `ЧЧ:ММ` (по умолчанию `09:00`)
- `DB_PATH` — путь к файлу SQLite (по умолчанию `./data/birthdays.db`)

## Запуск

```bash
npm start
```

Бот работает через long polling — отдельный сервер/вебхук не требуется.

## Использование

Добавьте бота в чат/группу (или пишите ему в личку) и используйте команды:

- `/add Имя Фамилия ДД.ММ.ГГГГ` — добавить сотрудника (год можно не указывать: `ДД.ММ`)
- `/list` — список всех сохранённых дней рождения с их ID
- `/remove ID` — удалить запись по ID
- `/today` — у кого сегодня день рождения
- `/help` — справка по командам

Напоминания приходят в тот же чат, где добавлены сотрудники, каждый день в `REMINDER_TIME`:
за 3 дня до дня рождения и в сам день.

## Деплой

Бота можно оставить работающим на любом сервере/VPS с Node.js 18+ (например, через `pm2`
или `systemd`), либо запустить в Docker-контейнере — важно только смонтировать директорию
с базой данных (`DB_PATH`) как постоянный volume, чтобы список не терялся при перезапуске.
